# Ritual Barber Studio

Sito web e materiale di marketing di Ritual Barber Studio, Corso Umberto I 300c, Bernalda.

- Prenotazioni: https://snappybooking.com/partner/107-ritual-barber-studio
- Instagram: [@ritual_barberstudio](https://www.instagram.com/ritual_barberstudio/)

## Struttura

| Cartella | Contenuto |
| --- | --- |
| `brand/logo/` | Logo originale (PDF di Illustrator), SVG su nero, PNG trasparenti bianco e nero |
| `media/instagram/` | Immagini e video pubblicati su Instagram, organizzati per campagna |
| `site/` | Il sito web 3D (in arrivo) |

## Identità visiva

Fondo nero con texture a fulmini, logo bianco, accento rosso, titoli in serif maiuscoletto, dettagli in corsivo serif, testi in sans.
